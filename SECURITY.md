# Security policy

## Supported versions

Only the [latest release](https://github.com/andriitrebukhin/ClickShift/releases/latest) gets security fixes.

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately via
[**Report a vulnerability**](https://github.com/andriitrebukhin/ClickShift/security/advisories/new)
on the repository's *Security* tab.

Include the ClickShift and macOS versions, the steps to reproduce, and what impact you expect.
If you attach `~/Library/Logs/ClickShift.log`, check it first: it holds button events and connection status only.

You'll get a reply as soon as possible. Please give the issue time to be fixed before you share details publicly.
